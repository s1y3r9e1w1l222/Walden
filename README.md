# Walden

Walden 帮你在自己的 Mac 上查看和整理已经同步到本机的消息。你可以直接用日常语言提出问题，也可以在需要时让它起草回复；发送前仍由你确认。

| 你想做什么 | Walden 可以帮你 |
| --- | --- |
| 查看文字消息 | 按时间和会话查看消息，保留发送者、时间和对话顺序。 |
| 看懂图片 | 查看消息中的图片，并结合可读的图片内容理解对话。 |
| 听懂语音 | 将支持的语音转成文字，和原消息一起查看。 |
| 按时间或会话查找 | 查看最近一段时间，也可以指定时段、单个会话或多种会话。 |
| 按联系人查找 | 用备注、昵称或别名查找私聊，也可查看该联系人在指定时段内实际发言的群消息。 |
| 整理工作与生活 | 回顾工作沟通、群聊通知、生活安排或过去的对话，按要求展示原文或摘要。 |
| 总结群聊 | 根据已取得的群聊发言，整理讨论重点。 |
| 提取待办 | 列出对话中明确提到的事项和已说明的负责人、时间；不明确的标为待确认。 |
| 回复消息 | 依据已取得的同一会话内容，提出私聊回复建议供你审核；你确认接收对象和完整内容后，才执行发送。 |

| 使用场景 | 可以这样问 |
| --- | --- |
| 工作沟通 | 总结项目群今天讨论的重点。 |
| 群聊通知 | 最近三小时有哪些明确提到我的消息？ |
| 生活安排 | 帮我回顾家人或朋友关于聚餐的安排。 |
| 对话待办 | 列出对话中明确提到的待办；负责人或时间没说清楚的标为待确认。 |
| 回顾对话 | 查看我和某人昨天的对话。 |
| 回复协助 | 根据这段私聊帮我起草回复，先给我确认。 |

图片和语音已经支持，相关功能经过审查和本机验证。具体结果仍取决于附件是否已下载、文件是否完好、格式及所需工具是否可用；处理失败时会说明情况，并保留原消息。识别和总结可能不准确，请核对重要信息。Walden 不会自动持续监控、执行待办或创建日历事项，也不能保证识别出所有需要关注的事项。

目前仅支持 macOS 上特定消息客户端的当前本地来源；支持的客户端和目录布局见 [安装与配置指南](docs/INSTALLATION.md)。

## 开始使用

1. 从 GitHub 下载或克隆源码，按[安装与配置指南](docs/INSTALLATION.md)依次安装 Walden 和查询技能。
2. 在 Codex 中说：“帮我配置 Walden 并查询最近一小时消息。”
3. 按提示提供本人在这台 Mac 上的单个账号数据目录；不清楚位置时，先请 Codex 协助确认，再由本人选择。
4. 配置开始前，保存工作并正常退出消息客户端程序，无需退出账号；如自动打开的窗口需要登录，请本人完成登录。
5. 等待配置成功。以后直接用日常语言查询，例如“看看最近三小时谁找过我”或“帮我回顾昨天的项目沟通”。

首次配置默认先准备最近三小时的消息，方便后续查询，也可以在配置时调整；**三小时不是日常查询的上限**。配置完成后，日常查询不用每次重新配置。后续可自选时间范围；较大范围会按提示确认。完整安装、配置和图片／语音工具准备步骤见 [安装与配置指南](docs/INSTALLATION.md)。

## 按自己的习惯查看

消息分类规则是可以手动修改的 Markdown 文件。你可以调整哪些已确认的群聊显示摘要或原文、是否纳入公众号，以及指定需要摘要展示的机器人会话；当次明确提出的查看要求也可以改变展示方式。修改后，查询 Skill 会在下次使用时读取规则。直接运行命令行时，需要自己选择相应参数，命令行不会自动读取这份规则。

默认情况下，普通私聊和未静音群展示取得的原文；已确认静音群展示摘要，并单列明确提到你的消息。公众号默认排除，可按规则或当次要求纳入。你也可以要求某些机器人会话只显示摘要，或在当次查询时要求不生成回复建议。

## 使用时请留意

- 已发现跨会话消息重复及归属不明的问题，原因尚未查明。遇到已观察到的来源冲突时，Walden 会阻断相关查询结果和依赖该来源的回复；这不能保证发现所有尚未观察到的冲突，也不能确定消息应归属哪个会话。
- 数据覆盖可能不完整；空结果不等于没有消息。私聊静音状态等信息也可能无法确认，不会被当作确定结果。
- 如发送结果无法确认，不要重复发送同一操作。查询结果、图片和语音都应根据你的授权使用。
- 本机已有受控验证，但不代表所有客户端版本、账号和系统环境都兼容。
