# 消息分类规则

查询消息前先核对本文。会话类型、静音状态、发送者及 @ 信息依据可靠的本地数据或用户明确设置判断，不凭昵称、消息内容或群聊身份猜测。

## 本人身份与收发方向

- 首次配置优先依据当前所选微信账号的可信资料确定本人唯一账号标识；无法可靠确定时，仅在首次配置时请用户确认。具体本人标识保存在用户本机私有数据源配置中，不写入开源默认配置。
- 查询时，以消息发送者唯一标识与当前数据源绑定的本人标识比较：相同为本人发出，可靠识别为其他发送者的消息按来源分类，系统消息单列，身份不明时保留未知。
- 昵称或备注变化不改变身份判断；切换账号或数据源时核对绑定，不沿用其他账号身份。
- “谁找我”不计入本人发言，但完整对话仍保留本人原文；普通群发言不自动视为专门找本人。
- “@本人”使用同一本人标识判断，“@所有人”单列；证据不足时保持未知。

## 会话分类

| 类别 | 默认处理 |
| --- | --- |
| 已可靠识别的公众号（订阅号／服务号） | 默认不读取消息正文及附件，不显示正文或摘要；当次明确要求查看时，在所选范围内读取并展示。 |
| 已确认静音的群聊 | 展示本次查询范围内的摘要；明确 @用户 的消息单独列出发送者、时间、事项及需要用户做什么。 |
| 用户明确指定只看摘要的机器人会话 | 展示本次查询范围内的摘要；明确要求原文时展开。不自动套用到其他机器人或同名会话。 |
| 普通私聊、未静音群及其余会话 | 首次就展示本次查询范围内实际取得的全部消息原文。 |
| 类型、静音或身份信息未知 | 明示具体未知项，保留原文；不据此猜测公众号、静音群或发送者。 |

用户当次明确指定的查看范围和原文／摘要要求优先。默认排除公众号，其余会话再按上述分类处理；不能因昵称相同而套用其他会话的设置。

公众号是否纳入读取由当前规则和当次请求决定。若规则改为展示公众号原文或摘要，应同时纳入相应范围的读取；不能仍沿用旧的排除设置。规则修改在下一次查询生效。

## 输出位置

- 默认直接在当前聊天正文展示查询结果，不生成文档、附件或页面，不以文件链接、文档或侧栏替代消息原文。仅在用户当次明确要求导出时提供文档。

## 原文与摘要

- 普通私聊、未静音群及规则规定展示原文的其他会话，直接在聊天中展示本次实际取得的全部消息原文，保留发送者、时间、顺序及本人发言。不先只给名单或条数，不按重要性删减；身份、类型或静音未知时仍展示原文并说明未知，不自动降为摘要。
- 内容过长时按会话和时间顺序分段展示，明确分段及未完部分；不因长度改成摘要、只摘重点或要求用户打开文档。遇到实际输出限制时，明确已展示范围和剩余部分，不宣称已展示完整。
- 摘要只用于本规则明确规定的会话类别，或用户当次明确要求摘要的情况。
- “谁找我”的收件统计与会话全文展示分别处理：用户自己的发言不计为别人来信，但仍保留在完整对话中；不能仅因本时段只有用户发言而省略已查询到的未静音会话。
- 摘要仅依据本次实际取得的内容，不补写未取得的上下文。明确区分 @用户、@所有人和普通群发言，不把一般群聊讨论推断为有人专门找用户。
- 说明查询范围、数据来源、实际数据时间及覆盖缺口。不能把已取得消息全部展示等同于真实来源完整；来源不可用或覆盖不足不能表述为“没有新消息”。

## 图片、语音及其他消息类型

- 先应用会话分类和查看范围，再对需要展示或摘要的图片、语音进行自动解析；不为被排除的消息解析附件，不要求逐条点名。
- 保留原消息的身份、发送者、时间及顺序。图片、语音分别保留 `[图片]`、`[语音]` 标记，识别结果注明“图片解析”或“语音转写”，与原文区分。
- 原文类会话逐条呈现解析结果，摘要类会话按既定分类汇总。
- 文件未取得、格式不支持、解码失败、无法识别或识别不确定时，逐项标明；不猜测人名、金额、时间或承诺，不阻塞已取得文本的展示。
- 链接、卡片、系统消息等保留实际取得的内容和类型；无法完整提取时说明缺失，不静默删除。

## 回复建议

- 消息查询默认在同一次回答中附适用的回复建议，按会话组织；用户明确只看消息时不生成建议。
- 回复建议放在对应会话的完整原文或规则规定的摘要之后，与原消息清楚分开；不以建议替代原文。
- 普通私聊、未静音群在完整原文后附候选回复。已经回复清楚或无需接话时注明“无需追加回复”，不重复拟答。
- 静音群默认不生成建议；明确 @用户 的事项仍需列出，但 @ 本身不构成生成建议或发送指令。用户明确要求回复该群时再拟建议。
- 机器人会话采用摘要，不自动改变其回复建议策略。
- 建议依据当前意图、同会话已取得的内容和已确认偏好，并考虑用户已经发出的回复。不编造事实或承诺；未知图片、语音等不足以支持拟答时，说明限制或暂不能可靠拟答。
- 回复建议与实际发送分开，发送须有明确选择或委托。

## 规则边界

本文仅定义消息分类及对应处理规则。展示、隐藏、摘要和解析不改变数据读取、模型使用、附件外发、通知、记忆或发送权限，也不代表相关能力已经实现或验收通过。
